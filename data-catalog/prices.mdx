## Sample Queries

### 1. ETH daily price for the last 30 days

```sql
SELECT block_date, price
FROM agent.ethereum_prices_day
WHERE symbol = 'WETH'
  AND block_date >= today() - 30
ORDER BY block_date
```

### 2. TRX daily price history

```sql
SELECT block_date, price FROM agent.tron_prices_day WHERE symbol = 'TRX' AND block_date >= '2026-01-01' ORDER BY block_date
```

### 3. Available Tron tokens with prices

```sql
SELECT symbol, contract_address, count() AS days_with_price FROM agent.tron_prices_day GROUP BY symbol, contract_address ORDER BY days_with_price DESC LIMIT 50
```

### 4. Available HyperEVM tokens with prices

```sql
SELECT symbol, contract_address, count() AS days_with_price FROM agent.hyperevm_prices_day GROUP BY symbol, contract_address ORDER BY days_with_price DESC LIMIT 50
```

### 5. Hourly prices for a Robinhood token

```sql
SELECT hour, symbol, price, price_source, observed_at FROM agent.robinhood_prices_hour WHERE contract_address = '0x0bd7d308f8e1639fab988df18a8011f41eacad73'
  AND hour >= now() - INTERVAL 7 DAY
ORDER BY hour
```

## Table Schemas

### `agent.ethereum_prices_day`

Daily token prices combining CoinGecko hourly snapshots and DEX VWAP calculations. One row per (contract_address, block_date, source). Prefer source='coingecko' when available.

**Engine**: MergeTree | **Partition**: `toYYYYMM(block_date)` | **ORDER BY**: `contract_address, block_date`

| Column | Type | Description |
|--------|------|-------------|
| `block_date` | `Date` | UTC block date |
| `blockchain` | `String` | Blockchain network name |
| `contract_address` | `String` | Token contract address (lowercase hex). Zero address for native token. |
| `decimals` | `Int64` | Token decimals (from erc20 metadata). Needed when converting raw amounts. |
| `symbol` | `String` | Token symbol. May be null for unregistered tokens. |
| `price` | `Float64` | USD price. CoinGecko source is hourly snapshot; DEX VWAP is volume-weighted from on-chain swaps. |
| `volume_usd` | `Float64` | Trading volume in USD |
| `source` | `String` | 'coingecko' or 'dex_vwap'. Prefer coingecko for stable reference; dex_vwap fills gaps. |

<Tip>

- Use argMax(price, source = 'coingecko') to prefer CoinGecko over DEX VWAP when both exist
- JOIN on (contract_address, block_date) for daily valuations
- WETH contract (0xc02aaa39b223fe8d0a0e5c4f27ead9083c756cc2) is the ETH price proxy on Ethereum
- Coverage gaps exist for illiquid/new tokens — always handle NULL prices

</Tip>

<Warning>

- CoinGecko prices are hourly snapshots, not tick-level — intraday precision is limited
- DEX VWAP can be skewed by low-liquidity pools or wash trading
- New tokens may have no price for the first few days after deployment
- Stablecoins may show slight depegs in CoinGecko data during volatility

</Warning>

<Tip>

- Dimension table — use as RIGHT side in JOINs
- Join key: (contract_address, block_date)

</Tip>

<Warning>

- Tron token addresses use base58 format — ensure join keys match
- Fewer tokens covered than Ethereum — many Tron tokens may lack CoinGecko prices
- DEX VWAP can be skewed by low-liquidity SunSwap pools

</Warning>

### `agent.robinhood_prices_hour`

Deduplicated hourly USD prices for supported Robinhood Chain token contracts. The agent view applies FINAL to the ReplacingMergeTree source so retry and backfill versions do not create duplicate contract-hour rows.

**Engine**: View | **Partition**: `toYYYYMM(hour)` | **ORDER BY**: `contract_address, hour`

| Column | Type | Description |
|--------|------|-------------|
| `hour` | `DateTime` | UTC price hour and logical time key. |
| `blockchain` | `String` |  |
| `contract_address` | `String` | Robinhood token contract address. |
| `symbol` | `String` |  |
| `decimals` | `UInt8` |  |
| `price` | `Float64` | USD price for the contract and hour. |
| `price_source` | `String` | Price-provider or derivation provenance. |
| `observed_at` | `DateTime` | Version timestamp used by the source ReplacingMergeTree. |

<Tip>

- Filter by contract_address and an hour range
- The agent view already applies FINAL; do not add another FINAL modifier
- Use observed_at to inspect when a contract-hour price version was produced

</Tip>

<Warning>

- Only explicitly supported tokens have prices; this is not every Robinhood token
- One price per hour, not OHLCV or intrahour observations
- Missing hours remain absent rather than forward-filled

</Warning>
